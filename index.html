Del resultado académico a Zotero

Zotero es un gestor bibliográfico gratuito que ayuda a recopilar, organizar, citar y compartir fuentes. Esta práctica prepara el flujo de trabajo; para guardar referencias en tu biblioteca real, usa Zotero y su conector de navegador.

1
Busca una publicación

En el catálogo, usa una frase concreta, por ejemplo: “ethnomathematics weaving” o “mathematics education”.

2
Revisa los metadatos

Comprueba título, autores, año, revista o fuente, DOI y enlace. Los metadatos incompletos deben revisarse antes de citar.

3
Guarda la referencia en Zotero

Instala Zotero Desktop y Zotero Connector desde el sitio oficial. Abre la página original de la publicación y pulsa el icono del conector cuando detecte una referencia.

4
Organiza y cita

Crea una colección para tu tema, revisa los datos importados y usa el complemento de Zotero para insertar citas y bibliografía en tu procesador de texto.

Configuración docente

Para que el aula funcione entre distintos dispositivos, crea un proyecto de Supabase, ejecuta el archivo supabase_setup.sql incluido en el paquete y añade los datos del proyecto aquí antes de publicar la web.

No pegues contraseñas ni claves secretas. La clave pública/publishable de Supabase está diseñada para uso desde el cliente cuando las políticas de seguridad (RLS) están bien configuradas. El archivo SQL incluido limita las operaciones a las necesarias para la actividad. Revisa la configuración antes de usarla con estudiantes.
1
Crea el proyecto

Entra a supabase.com y crea un proyecto. Copia su URL y su clave pública desde el panel de API.

2
Crea la tabla y las políticas

En SQL Editor, ejecuta el archivo supabase_setup.sql que acompaña esta página.

3
Publica la página

Sube index.html a un repositorio público de GitHub y activa GitHub Pages. Luego comparte el enlace publicado con tu grupo.

4
Configura el aula

En esta misma página, pega la URL y clave pública del proyecto y pulsa «Guardar conexión». Cada estudiante introduce el mismo código del aula y un alias.
